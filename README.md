# Robô — Desafio de Obstáculos

_Projeto de robótica desenvolvido para representar a Escola Mário Gomes em um campeonato de robótica._

# 🎯 Sobre o Projeto

Este projeto consiste no desenvolvimento e programação de um robô capaz de percorrer um percurso de um ponto a outro, enfrentando e desviando de obstáculos ao longo do caminho.

O objetivo é desenvolver uma solução capaz de completar o percurso de forma eficiente e consistente, combinando programação, automação e controle do robô.

# 🏫 Representação

Escola: Mário Gomes
Competição: Campeonato de Robótica
Ano: 2026

O projeto está sendo desenvolvido como parte da participação da Escola Mário Gomes na competição.

# 🏆 Desafio

Durante a competição, o robô deverá:

- Percorrer o percurso definido pela competição;
- Sair do ponto inicial e chegar ao destino;
- Identificar e lidar com obstáculos;
- Executar os movimentos de maneira controlada;
- Buscar completar o percurso com eficiência e confiabilidade.

# 🧠 Programação

O código deste repositório contém a programação utilizada no desenvolvimento e nos testes do robô.

Arquivos

Arquivo| Função
```
"code.leg3"| Código principal do robô
"code.sim3"| Arquivo utilizado para simulação e testes
```
A linguagem .leg3 é desenvolvida pela empresa Legal. Esta linguagem é própria para um tipo de robô(módulo) responsável pela execução de movimentos.

A sintaxe é em português brasileiro. Ou seja, é bem fácil e intuitiva para se mexer.

# 🔧 Desenvolvimento

O desenvolvimento do robô envolve diferentes etapas:
```
Programação
     ↓
Simulação
     ↓
Testes
     ↓
Identificação de problemas
     ↓
Ajustes
     ↓
Novo teste
```
Esse processo permite aprimorar gradualmente o comportamento do robô antes da competição.
